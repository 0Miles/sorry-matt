# Speak human：先對帳，再講人話

每次改寫都走完三步：建立**語義帳本**、做**母語重寫**、逐項**回帳**。共享的是這套過程，
不是任何單一語言的詞數、時態、語態或標點規則。

## 1. 建立語義帳本

先從請求、原文與對話鎖定：

- 目標語言與 locale；未指定且無法可靠推斷時，沿用原文變體。
- 受眾、用途、語氣，以及使用者要改寫文字還是要用人話解釋內容。
- 文本需要的強度：程序、錯誤訊息、安全文字、工具說明與 agent 指令重精確；一般回答與文件
  重自然；署名文章與對話重作者聲音。

在內部建立**語義帳本**，逐項記錄：

- 主體、動作、對象、事實、數字、單位與專有名稱。
- 條件、例外、否定、fallback、因果與各自的作用範圍。
- 時間、順序、完成或持續狀態，以及目前是否仍有效。
- 不確定程度、證據來源與義務強度，例如可能、通常、據報、可以、應該、必須。
- 原文明確知道、不知道或只是假設的部分。

同時裁決特殊文本：逐字引文保持原樣；法定、合約與規範原文另做摘要，摘要不冒充原文；創作與
說服文字保留聲音、節奏與有意義的修辭，只改使用者指定的問題。

原文有多種合理解讀時，在帳本中保留全部解讀範圍。只有改寫能維持同樣範圍時才動原句；否則
保留原句，並把需要澄清之處列入輸出。

完成判準：目標語言、locale、受眾、用途與輸出類型均已確定；原文每項主張及其作用範圍、
確定程度與責任歸屬都恰好登記一次。

## 2. 做母語重寫

丟開原句骨架，根據語義帳本在目標語言中重新造句：

- 使用該 locale 當代、常見、中性的詞語、搭配、語序、代詞、省略、時貌、語氣、敬語與標點。
  使用者原本自然且正確的用詞優先。
- 同一實體、狀態或動作固定使用同一名稱。代詞與省略只用在指涉唯一、而且該語言自然允許的地方。
- 原文沒有說話者、動作者、責任人或受益人時，採用目標語言自然的無主詞、非人稱或事件表達。
  只有原文明確推出某角色，而且寫出來能消除實質歧義時，才把角色明示。
- 角色可能混淆時，寫清楚誰做、做什麼、對什麼做、何時做，以及在哪個條件下做；依目標語言
  選擇自然語態，而不是一律補主詞或改主動句。
- 每個 discourse unit 承載一個主要主張或動作。不可分的同時動作與即時結果可以合併；其餘
  拆句或列點。
- 先寫讀者必須知道的條件，再寫依賴它的動作。讓例外、否定與 fallback 只指向它們限制的內容。
- 能直接表達動作時，使用自然的動詞或述語，取代空泛名詞化與支援動詞，例如把
  `進行問題的識別` 改成 `找出問題`。
- 精確文本使用可由字面理解的表達；一般對話可保留受眾熟悉、指向明確的慣用語。
- 必要術語保留並在首次出現時自然解釋；後文遵守既有 glossary，不為文采輪換近義詞。
- 套話、同義反覆、重複 hedge 與無證據宣傳詞沒有帳目可對時直接刪除；真正承載不確定性、
  限制或禮貌關係的詞保留。
- 一段只處理一個主題；步驟、平行條件、選項與複雜列舉使用列表或表格。

以命題密度、修飾層級與指涉負擔判斷複雜度。語言 profile 可以另訂限制；通用層不使用固定
詞數、字數、句數或標點上限。文字清楚、自然且資訊完整時就停止縮短。

原文已經自然、清楚並符合受眾時，原文就是母語重寫的結果。

完成判準：帳本中的每個項目都能在改寫中定位；改寫中的每項主張都能回溯到帳本；詞語與句法
來自目標語言，而不是來源語言的逐字替換或句型搬運。

## 3. 回帳並輸出

把改寫逐項映回語義帳本，再做母語檢查：

1. 是否有帳本項目遺失，或輸出主張沒有來源？
2. 是否改變不確定程度、證據強度、因果、義務、能力、時間、責任或作用範圍？
3. 是否新增原文沒有的我、我們、系統、使用者或其他角色？
4. 熟練母語者在這個 locale、受眾關係與文體中會這樣說嗎？
5. 是否仍有來源語言的搭配、語序、名詞化或其他翻譯痕跡？
6. 每個代詞、省略、條件、例外與否定是否只有一種合理指向？
7. 讀者能否快速找出適用條件、下一個動作與預期結果？

衝突的判決順序固定為：語義與責任正確 → 使用者指定的語言、locale、受眾與文體 → 資訊可用 →
母語自然 → 簡短與格式偏好。

預設只輸出完成後的文字。使用者要求 before/after、diff 或理由時，才輸出：

| 原文 | 問題 | 改寫 |
| --- | --- | --- |
| 原句或片段 | 語義或自然度問題 | 改寫結果 |

只有無法安全消除的歧義，才在改寫後加一行澄清事項。

完成判準：零遺失帳目、零無來源主張、零已知 locale 衝突；輸出格式符合使用者要求，而且沒有
額外的 skill 說明、模式、違規數、修改摘要或結尾邀請。
